## 名称方案

**正式名：妙笔 · Prompt Enhance**

- 简洁易记：两个字，取「妙笔生花」，无需解释就知道是"帮你把文字变好"
- 体现功能：一键把随手的草稿点成高质量的提示词
- 英文副名 Prompt Enhance 直接对齐包名与命令 `/enhance-prompt`，检索友好

备选（按优先序）：灵笔（灵犀之笔，更"AI 感"）、润笔（"润"字最贴改写动作，但现代语义偏"稿酬"）。

一句话简介（用于列表页）：

> ✦ 一键把随手写的草稿变成高质量提示词。用会话当前的模型，一次调用，失败绝不动原文。

## 功能介绍

妙笔在 dsh 输入框右侧加一枚 ✦ 按钮（紧贴模型选择器左侧）。点击后，插件把输入框里的草稿交给**当前会话正在使用的模型**做一次改写，并把改写结果直接写回输入框——不用跳出对话、不用复制粘贴、不用另开窗口。

- **一键改写**：草稿非空即可点击，数秒后输入框内容替换为改写后的提示词
- **真取消**：增强中再点一次即真中断请求（AbortSignal 直达模型层），不算失败、不弹错误
- **失败保原文**：任何失败（模型不可用、超时、网络问题）都不动草稿一个字符；按钮转警告态，给出人话原因 + 机器诊断码，再点即重试
- **一键还原**：成功后出现还原按钮，后悔了随时恢复原文
- **竞态保护**：增强期间你手改了草稿，改写结果到达后自动丢弃，绝不覆盖你的输入
- **隐私优先**：草稿以编码形式传输，命令日志不记录任何明文；host 日志只记长度、耗时与结果码
- **会话感知**：自动使用会话当前生效的模型，无需配置；跨会话状态天然隔离
- **双语界面**：中文 / 英文文案自动跟随；键盘可达，无障碍属性齐全

技术形态：零改动内核的双半插件，只使用 dsh 公开扩展点（slot / `ctx.commands` / `ctx.llm` / 已挂载 remote）。架构上内核与平台分层：协议编解码、状态机、错误归一化、提示词资产全部是平台无关的纯函数（host 半边对 dsh 包零运行时值导入），平台耦合面只有四个适配点——移植到其他 agent 框架只需实现等价的四个适配函数。提示词资产逐字符复用 WorkBuddy 同款（带 sha256 锚点校验）。

## 适用场景

- **写不清自己要什么时**：「帮我写个产品介绍」→ 一键变成目标、结构、语气、限制都交代清楚的完整 prompt
- **提示词太长太乱时**：把口语化的长段落收敛成结构清晰的指令
- **想学习怎么写 prompt 时**：对比改写前后，看模型如何理解与重构你的意图
- **反复调试 prompt 时**：失败自动保原文，随手改随手增强，不用怕丢稿

## 使用方式

1. 安装（见仓库 README）：构建 → 挂进 `web` 与 `desktop` 两个 profile → 真重启 DSH Desktop
2. 在输入框写好草稿（非空即可）
3. 点输入框右侧的 ✦ 按钮，或输入 `/enhance-prompt <文字>`
4. 等待按钮转圈结束；结果自动写回输入框
5. 不满意：再点一次重试；点 ✦ 旁的还原按钮恢复原文；增强中点 ✦ 即取消
