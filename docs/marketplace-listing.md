# 插件市场介绍材料 · DSH 入口

本页面向 DSH 插件列表，完整跨平台状态以 [项目介绍](../README.zh-CN.md) 为准。保留包名 `dsh-prompt-enhance`，展示名使用“妙笔 · Prompt Enhance”。不要与其他作者的同名市场条目混淆。

## 一句话介绍

> 在输入框中一键把草稿改成更清楚的提示词，支持取消、恢复原文与防覆盖保护。

## DSH 功能介绍

妙笔在 DSH 输入框模型选择器附近添加 ✦。它调用当前会话路由的模型改写当前草稿，并原地回填；增强中再次点击取消，成功后可恢复原文，失败或编辑冲突时保留用户输入。

- 适合口语化开发任务、写作要求和已有约束整理。
- 使用 DSH 公开扩展点，不修改 DSH 内核。
- 默认最多 20,000 字符，超时 120 秒；不自动发送消息或执行任务。
- 草稿会发给当前模型服务并消耗配额；命令日志不记录草稿参数。base64url 只是编码，不是加密。
- 每次增强会留下命令节点；历史验证 DSH Desktop 2.0.5，其他版本需实际装载验证。

## 安装与其他入口

见 [DSH 安装与卸载](dsh-installation.zh-CN.md)。T3 和 Codex Desktop 采用独立实验性适配，安装此 DSH 插件不会在其他应用自动生成按钮。

推荐模型与适用场景见 [模型选择](model-selection.md)；DeepSeek Flash 关闭思考的快速路线目前在 T3 中验证，不应描述成所有 DSH 会话的默认配置。
